# 浮世 · 潮汐 / UKIYO TIDES

以葛饰北斋《神奈川冲浪里》为灵感的身体交互艺术网页。课程：交互设计及可行性。

## 页面布局

严格沿用课堂 `kusama-starter`（草间弥生）模板的全屏画布、无页面滚动、居中开始卡片与左下角状态提示；保留模板的卡片尺度与操作层级；按包豪斯方向改为米白底、黑色几何边框、朱红矩形按钮与无衬线字体。操作说明和可选设置集中在开始卡片，不使用导航、长页面或卡片网格。

## 设计说明

作品以“让身体成为海的呼吸”为概念，从原画提取巨浪、富士山、舟船与海平线，分别转译为同心圆弧、黄色三角形、朱红梯形与水平色带。以米白留白、蓝色主形、朱红圆形建立包豪斯式构成。横屏与竖屏分别排版，并完整适配画布，避免裁掉构图重心。水纹位移与细线仅作用于蓝色色块，避免亮斑破坏几何秩序。

- 挥手：手腕位置影响局部水纹，运动速度增强波动并产生浪花。
- 张臂：以双腕间距除以肩宽，计算身体尺度无关的张臂程度，控制潮势与海声音色。
- 举手：双手高于鼻部时，出现暖金色浪花并触发五声音阶音符。
- 无摄像头：鼠标/触屏移动造浪，点击激起涟漪，按住增强潮势。
- 可切换合成海声、全屏体验、保存 PNG、重置画面。
- B 开启/关闭身体交互，空格暂停，M 切换声音，S 保存，R 重置，Esc 返回说明。开始卡片中的“交互设置与原作资料”提供触屏按钮。键盘焦点在按钮/链接上时保留原生操作。

## 三种互动玩法

- **01 潮汐（键盘 1）**：拖动红日、巨浪、山形和舟船；滚轮缩放，Shift＋滚轮旋转；触屏双指可同时缩放旋转。身体模式下左手牵动红日、右手牵动舟船，张臂改变圆弧尺度，双手举起切换配色并触发几何脉冲。
- **02 构成（键盘 2）**：显示构成网格和选中边框，拖动松手后位置吸附 24 单位网格，旋转吸附 15 度角；此模式暂停身体对几何位置的控制，方便自由编排。
- **03 节奏（键盘 3）**：四个元素以八步序列交替脉冲，动作能量与张臂程度改变节拍速度；点击元素可以即兴触发音符与环形反馈。按 M 开启声音。
- 双击画布或按 C 在三套配色间切换；R 重置形状位置、尺度、角度与配色；S 保存当前构图。
- 几何构成每秒最多更新 25 次，水纹按浏览器帧率绘制，适配横竖屏。

## 本地运行

不要直接双击 HTML 使用摄像头。进入目录后运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8765 。Mac 也可双击 `启动作品.command`。

所有图片、人体模型、MediaPipe JS/WASM 均包含在项目中；首次下载项目后运行无需 CDN。无需 npm 安装或构建。摄像头需要 localhost 或 HTTPS。身体模式建议用 Chrome / Edge，光线充足，退后让头、肩和双手进入镜头。

仓库名建议 `ukiyo-tides`。上传此文件夹全部内容（无需上传本文件夹外的课堂资料或开发临时文件）。

- 输出目录：`.`（仓库根目录）

## 实现与可行性

原生 HTML/CSS/JavaScript，WebGL 片元着色器负责海面位移，Canvas 2D 绘制粒子与涟漪，MediaPipe Pose Landmarker 识别人形，Web Audio 合成声音。最多识别 1 人，检测频率约 15 Hz，像素比上限 2，粒子数上限 160；设备不支持 WebGL 时保留原画、粒子和基本交互。

模型输出 33 个关键点，交互使用鼻部、双肩、双腕。坐标镜像与动作平滑减少抖动，肩宽归一化减少人与镜头距离变化的影响。动态效果是艺术化水纹位移，不是物理流体模拟。身体模式需要现场允许摄像头并由真人验证。

## 隐私

不使用后端、账号系统、统计脚本或上传接口。相机画面仅在当前设备推理；不请求麦克风，不上传视频或姿态数据。关闭身体模式、切换后台或离开页面会停止相机轨道。
